# Python-Vault
📚STUDY PAL
 is a Python-based command-line study planner designed to help students organize their academic tasks and keep track of their study progress. It provides a simple way to create, manage, search, and complete tasks from one place.

## Key Features

### Add a Task
Users can add a new task by entering its name, subject, priority, due date, and current status. Each task is stored with these details so it can be managed later.

### View Tasks
Displays all saved tasks along with their relevant information, allowing users to quickly check their upcoming and completed work.

### Complete a Task
Users can select a task and mark it as completed once they finish it. The task's status is then updated in the saved data.

### Delete a Task
Allows users to remove tasks that are no longer required.

### Search Tasks
Users can search for a particular task using its name or other relevant information instead of going through the entire task list.

### Filter Tasks
Tasks can be filtered according to categories such as subject, priority, or status, making it easier to view specific types of work.

### Progress Tracking
StudyPal calculates and displays the user's progress based on completed and pending tasks, providing a quick overview of their study activity.

### Study Timer
A built-in timer allows users to set a study session and focus on their work for a selected period.

## How It Works

When the program starts, users are presented with a menu containing the available options. They can choose an action such as adding, viewing, completing, deleting, searching, or filtering tasks, or starting the study timer.

Task information is organized using Python data structures and saved in a JSON file. This allows the tasks to remain available even after the program is closed and opened again.

## Technical Overview

- *Language:* Python
- *Interface:* Command-Line Interface (CLI)
- *Data Storage:* JSON
- *Core Concepts:* Lists, Dictionaries, Functions, Loops, Conditionals, File Handling
